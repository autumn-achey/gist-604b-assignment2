# gist-604b-assignment2
GIST 604B Assignment 2: QGIS Desktop GIS Projects

Overview
- This repository is a compilation of 10 different tutorials I completed in order to learn how to work in QGIS. This repository represents going from no experience with QGIS, to doing more and more complicated work within the program.
- In these tutorials, a multitude of GIS skills were practiced including raster work, vector work, and joins.

Software Environment
- QGIS 4.2.3
- Windows 10
- No plugins used

Completed Tutorials
- Making a Map (http://qgistutorials.com/en/docs/3/making_a_map.html) 
- Working with Projections (https://www.qgistutorials.com/en/docs/3/working_with_projections.html)
- Working with Attributes (https://www.qgistutorials.com/en/docs/3/working_with_attributes.html)
- Importing Spreadsheets or CSV Files (https://www.qgistutorials.com/en/docs/3/importing_spreadsheets_csv.html)
- Basic Vector Styling (https://www.qgistutorials.com/en/docs/3/raster_styling_and_analysis.html)
- Basic Raster Styling and Analysis (https://www.qgistutorials.com/en/docs/3/raster_styling_and_analysis.html)
- Performing Table Joins (https://www.qgistutorials.com/en/docs/3/performing_table_joins.html)
- Performing Spatial Joins (https://www.qgistutorials.com/en/docs/3/performing_spatial_joins.html)
- Performing Spatial Queries (https://www.qgistutorials.com/en/docs/3/performing_spatial_queries.html)
- Working with Terrain Data (https://www.qgistutorials.com/en/docs/3/working_with_terrain.html)

Skills Demonstrated
- Map layouts
- Layer projections (Coordinate reference systems)
- Isolating specific attributes
- Working with CSV files and spreadsheets in QGIS
- Table joining
- Spatial joining
- Spatial queires
- Creating contour maps

Reflections
- The basic of QGIS are much easier to understand after these tutorials, especially find tools and other options the user would use all the time. Throughout this process, importing different types of data and configuring them as needed is much clearer. The biggest challenge throughout these tutorials was finding everything I needed within QGIS as the layout is different that ArcGIS Pro which I am more used to. I anticipate using these skills to make more complex maps.
